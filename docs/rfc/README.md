# docs/rfc/

RFCs (*Request for Comments*): propuestas de decisión técnica o de producto que necesitan discusión **antes** de tomarse — a diferencia de un ADR (`docs/adr/`), que registra una decisión que **ya** se tomó. Ver `docs/standards/documentation.md`.

Vacía hoy a propósito: con un equipo de un desarrollador y una socia no técnica, las decisiones se toman directamente (y quedan como ADR si son de arquitectura). Este mecanismo se activa el día que haya más gente técnica involucrada y una decisión necesite debatirse por escrito antes de cerrarse — no antes, para no burocratizar decisiones que hoy se resuelven en una conversación.
