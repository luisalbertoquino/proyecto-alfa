# docs/meetings/

Actas de reuniones de negocio entre el usuario y Angie (socia) — decisiones tomadas, pendientes, y contexto que no vive en ningún otro documento formal.

Convención sugerida por archivo: `AAAA-MM-DD-tema-corto.md`, con al menos "qué se decidió" y "qué queda pendiente". No es un documento vivo como `docs/estado-actual.md` — cada acta es un registro puntual de una fecha específica, no se edita después.

Vacía hoy porque las reuniones hasta ahora se han resuelto directamente en la conversación con Claude Code y quedan reflejadas en `docs/estado-actual.md`. Empieza a usarse cuando haya una reunión cuyo contenido valga la pena registrar aparte (ej. la primera revisión de diseño/funcionalidad con Angie).
